# Contributing

This repository does not accept outside contributions. Only maintainers can open pull requests here. This applies to changes written by hand and to those written by AI agents or bots.

- Bugs and feature requests go to [sahina/ironflow-issues](https://github.com/sahina/ironflow-issues/issues/new/choose). Describe the problem; do not send a patch.
- Security problems go through a [private advisory](https://github.com/sahina/ironflow-issues/security/advisories/new), never a public issue.
